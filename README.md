# 99 카드게임

친구와 방번호로 같이 하거나, 혼자 봇과 하는 웹 카드게임. 설치/빌드 없이 `index.html` 하나로 동작해요.

## 하는 법
- 카드를 한 장씩 내서 합계를 올려요. **합계를 99 넘게 만든 사람이 져요.**
- 친구와 하기: 방번호를 정하고("랜덤" 버튼으로 만들 수도 있어요) 같은 주소의 친구에게 알려 주세요. 처음 그 번호로 들어온 사람이 방장이에요.
- 혼자 하기: 첫 화면의 "혼자 하기"에서 봇 수(1~3명)를 고르고 시작해요.
- 카드 효과는 게임 화면 아래 "룰 보기"에 있어요.

## 배포 (GitHub Pages)
1. 이 폴더의 파일을 저장소에 올려요(`index.html`은 저장소 맨 위에).
2. 저장소 Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 선택해요.
3. 나오는 주소를 친구에게 보내요.

## 개발
- 개발 안내(규칙/구조/네트워크 프로토콜/주의사항)는 [CLAUDE.md](CLAUDE.md)에 있어요. Claude Code로 이 폴더를 열면 자동으로 읽어요.
- 테스트: `npm test` (Node 18 이상)
- 로컬 실행: `python3 -m http.server 8000`
